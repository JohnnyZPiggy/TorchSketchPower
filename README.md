# TorchSketchPower

Experimental portable PyTorch implementation of sketch-power subspace iteration, inspired by Chang & Yang (2026), DOI: 10.1137/25M1760143.

**Status:** Initial research prototype. No verified one-pass low-rank reconstruction, GPU performance claims, or upstream code reuse.

Project coordination: [Issue #1](https://github.com/JohnnyZPiggy/TorchSketchPower/issues/1).

SAE V3.3 pinned source: `JohnnyZPiggy/SAE-Framework@65338eb1aa67971e110db982a07cf43161c23446`. A complete pinned `.sae/` snapshot is **not yet adopted**.
